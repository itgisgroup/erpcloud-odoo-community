# ERPCloud Video Library — Odoo 20 Community

Organize published YouTube videos in a responsive website library. Add the included snippet to a website page or use the standalone `/video-library` page.

## Included

- Video records, categories, tags, featured flag and manual duration label
- YouTube URL and ID validation before publishing
- Public JSON-RPC feed of published videos
- Interactive category filters, safe DOM rendering and a branded thumbnail fallback
- Responsive video page and drag-and-drop website snippet

## Install and use

1. Install on Odoo 20 Community with standard `website`, `mail` and `portal` apps available.
2. Create a category and video, set its public YouTube URL, then publish it.
3. Open `/video-library` or add the Video Library snippet to a website page.

Normal installation creates no sample video. YouTube thumbnails require the visitor's browser to reach YouTube; the library shows its branded fallback when a thumbnail is unavailable. Duration is entered manually.
