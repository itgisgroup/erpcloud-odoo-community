# ERPCloud Blog & News — Odoo 20 Community

Publish articles on your Odoo website using an editorial workflow. Authors draft posts, editors review and publish them, and visitors can submit moderated comments.

## Included

- Categories, tags, rich text posts, excerpt and estimated reading time
- Draft, review and published states; author, editor and manager access groups
- Responsive list and article pages at `/blog` and `/blog/<slug>`
- Public JSON-RPC listing for published posts only
- Moderated visitor comments and view counters
- Editable SEO title and description fields in the backend

## Install and use

1. Install on Odoo 20 Community with standard `website`, `mail` and `portal` apps available.
2. Give editorial users the Blog Author, Blog Editor or Blog Manager group.
3. Create a category and post, then publish it. Normal installation adds no sample article.
4. Open `/blog` to verify the website page. Review comments in the module's own menu.

This release does not automatically schedule publication or inject Open Graph or Schema.org metadata.
