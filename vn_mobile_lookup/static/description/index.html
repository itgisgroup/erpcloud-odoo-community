Vietnam Mobile Lookup

Find a contact using the same Vietnamese mobile number in local or international format.

One number, several ways to type it

A contact saved as +84 912 345 678 appears when you search for 0912345678. Spaces and dashes in full mobile numbers are accepted.

See it in Odoo

The demo contact keeps its original +84 number. Searching the 0 form returns the same contact.

Built for everyday contact lookup

  • Works in the Contacts name search and Odoo contact suggestions.
  • Uses indexed lookup keys; original phone values stay intact.
  • No account, API key, external service, or configuration required.
  • Respects the user's existing Odoo record access.

Scope

Recognizes full Vietnamese ten-digit mobile numbers beginning with 03, 05, 07, 08, or 09. This app does not validate ownership, block duplicates, or search partial mobile numbers. Contacts explicitly assigned to another country are not included in Vietnamese equivalent-format lookup.

Requirements

Tested on Odoo 20 Community in a self-hosted environment with the standard Contacts app. Odoo.sh and Enterprise have not yet been tested. Python addons cannot be installed on Odoo Online.
